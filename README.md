## 

##### ⓘ  Descripción

  - Búsquedas web en múltiples plataformas ordenadas por categorias


##### ⚙ Características:

    ╰─ Busca un mismo término en múltiples plataformas
    ╰─ Conecta con una VPN para evitar bloqueos

###### ☰ Dependencias:
    ```bash
    firefox gnome-terminal protonvpn-cli 
    ```    

##  
##### 🛠 Instalación:

1. Dar permisos de ejecución:

   ```bash
    chmod u+x BUSCADORES-WEB.sh
   ```

2. Ejecutar el script:

   ```bash
    ./BUSCADORES-WEB.sh
   ```
 
##  
###### » Uso:
   ```bash
    ./BUSCADORES-WEB.sh
    
    Modo privado:
    ./BUSCADORES-WEB.sh [p]
    * Necesita un perfil en firefox llamado 'p' y configurarlo al gusto
   ```
